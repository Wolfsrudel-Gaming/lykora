# Mitmachen

Beiträge sind willkommen: Code, Rätselideen, Doku, Tests im Gelände.

- **Fragen und Ideen:** GitHub Discussions
- **Fehler und Aufgaben:** GitHub Issues, geschnitten in Meilensteine
- **Pull Requests:** klein halten, `npm test` muss grün sein
- **Doku:** Deutsch und Englisch

Mit einem Beitrag stimmst du zu, dass er unter der [AGPL-3.0](LICENSE) veröffentlicht wird.

Bitte kein Rotkreuz-Zeichen in Logos, Grafiken oder Spielinhalten verwenden; es ist gesetzlich geschützt.
